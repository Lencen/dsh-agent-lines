给 DSH Agent 的
持久消息线

一个管理线，多条执行线。每条线是普通 DSH Session，有独立上下文和持久收件箱；消息落本地 SQLite，跨进程共享，不依赖网络服务。

curl -fsSL https://raw.githubusercontent.com/Lencen/dsh-agent-lines/main/install.sh -o install.sh && bash install.sh

demo profile · 通用 label · 不含内部数据

为什么不是再做一个聊天框

线是可寻址的

agent#line 是稳定身份；管理线可以按角色建线、发任务、收结果。

消息是持久的

接收方重启后消息仍在；至少一次投递，Session 日志用 requestId 做幂等。

边界是清楚的

0.3 只做本地 SQLite；不做 handover、不做进程隔离、不内置团队 UI。

首次使用：一个管理线 + 8 条成员线

你是开发团队负责人：负责任务拆解、分配、协调、跟踪、汇总。
请用 line_create 创建：
research / architecture / uiux / dev / test / acceptance / release / ops
创建后用 line_list 确认，然后待命。
