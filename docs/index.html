它替你省掉什么

不用反复讲背景

每条成员线是一个独立的 DSH 会话，长期保留自己的上下文；新任务直接派给对应角色。

不用自己当调度

负责人拆任务、分配、协调、处理分歧、收结果；你只需要看最后的汇总。

不用怕关窗口

任务和消息保存在本地；重启 DSH 后还能接着做，成员状态和未处理消息都在。

适合长期项目、多角色协作。

一个真实用法

1. 你说目标

“给报表页加 CSV 导出，带测试和一页 runbook。”

2. 负责人组队

拆成调研、架构、UIUX、开发、测试、验收、发布、运维，按角色建线。

3. 团队并行

成员各自做事；负责人追进度、处理接口分歧，必要时重新分配。

4. 你收结果

负责人汇总结论、文件路径、风险和遗留问题；不用自己挨个问。

首次使用：让负责人自己组队

使用 dsh-agent-lines。先把这个会话设为开发团队的管理线；如果还没绑定，就先完成绑定。

你是开发团队负责人：负责任务拆解与分配、协调沟通、跟踪进度、汇总结果、总结汇报。你只做管理和协调，不执行具体开发任务。

请组建开发团队。成员名字用简短英文，岗位用中文：
research（调研）、architecture（架构）、uiux（UIUX）、dev（开发）、test（测试）、acceptance（验收）、release（发布）、ops（运维）。

团队建好后先待命，不要自动开工，等我发第一个任务。

安装或更新后需要重启 DSH Web。技术细节、协议和限制见 README / 架构文档。社区插件，不是 DeepSeek 官方产品。
